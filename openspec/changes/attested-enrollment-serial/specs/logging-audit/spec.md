## MODIFIED Requirements

### Requirement: Audit-событие device_enrolled

Engine ДОЛЖЕН (MUST) эмитить audit-событие `device_enrolled` после успешного импорта
enrollment-пакета: host_id prefix8, поле serial per-host серта, применённый `bundle_version`,
режим (standalone/managed). Событие ДОЛЖНО (MUST) попадать в локальный hash-chain журнал
(audit-visibility); выгрузка в Control — best-effort при связности.

Поле serial ДОЛЖНО (MUST) заполняться только из источника, покрытого подписью бандла. В
managed-режиме таким источником ДОЛЖЕН (MUST) быть проверенный `manifest.toml`: серийник едет
там рядом с `p12_sha256`, под той же подписью и тем же `bundle_version`. Значение ДОЛЖНО (MUST)
попадать в событие только после того, как подпись манифеста проверена.

Серийник в манифесте ДОЛЖЕН (MUST) присутствовать вместе с `p12_sha256` и НЕ ДОЛЖЕН (MUST NOT)
приниматься без него: серийник без пина на байты описывает сертификат, которого в установленном
контейнере может не быть. Манифест, где есть одно и нет другого, ДОЛЖЕН (MUST) отвергаться как
некорректный.

Engine НЕ ДОЛЖЕН (MUST NOT) выводить серийник из самого `.p12`. Каким сертификатом устройство
аутентифицируется, решает совпадение с закрытым ключом контейнера; ключ без пароля не прочесть, а
пароля на шаге импорта нет. Всё, что читается из контейнера без пароля, выбрано тем, кто контейнер
собрал.

В режиме standalone поле serial ДОЛЖНО (MUST) оставаться пустым: заверить значение там нечем.

#### Scenario: Успешный managed enrollment
- **WHEN** enrollment-пакет импортирован, подпись манифеста проверена и `tessera check` прошёл
- **THEN** эмитится `device_enrolled` с host_id prefix8, serial из проверенного манифеста, bundle_version и режимом

#### Scenario: Манифест называет серийник без пина на байты `.p12`
- **WHEN** в манифесте есть серийник, но нет `p12_sha256` (или наоборот)
- **THEN** манифест отвергается, импорт не выполняется, эмитится `enrollment_rejected`

#### Scenario: Standalone enrollment
- **WHEN** пакет импортирован в режиме standalone, где подписи нет
- **THEN** эмитится `device_enrolled` с пустым полем serial; импорт не прерывается
