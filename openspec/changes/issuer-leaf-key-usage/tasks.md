## Обнаружено при проверке фикса (вне объёма этого изменения)

- [ ] 7. **Дефолты версии формата расходятся**: `issuer` по умолчанию выпускает
  `profile_version = 1` (`cli.rs:172`), а Engine по умолчанию принимает максимум `0`
  (`DEFAULT_MAX_SUPPORTED_PROFILE_VERSION`, с пометкой «until the `[trust]` config key
  is wired through» — при том что ключ уже проводится). Спеки не фиксируют, какая версия
  текущая. Параметр `max_supported_profile_version` не документирован в
  `dist/config/config.toml.example`. Требуется решение: поднять дефолт Engine, опустить
  дефолт issuer или задокументировать обязательную настройку — отдельным изменением
- [ ] 8. **Сквозной вход требует выбора роли**: `ca_extensions` всегда добавляет рамки
  делегирования, поэтому проверка требует непустую роль (`delegation_denied`,
  `violated_check="role"`, `no role selected`) даже когда `[roles]` не настроены.
  Пересекается с нереализованной моделью ролевых учётных записей; проверить, ожидаемо ли
  это для выдачи без ролей
