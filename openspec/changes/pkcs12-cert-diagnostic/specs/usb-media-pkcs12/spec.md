## MODIFIED Requirements

### Requirement: Диагностика wrong-PIN

Извлечение сертификата для диагностики ДОЛЖНО (MUST) выполняться разбором, который обходит
`AuthenticatedSafe` контейнера сам и берёт `CertBag` только из незашифрованных разделов
`id-data`. Разбор НЕ ДОЛЖЕН (MUST NOT) зависеть от того, расшифровывается ли ключевой мешок:
закрытый ключ в контейнере зашифрован всегда, и разбор, спотыкающийся о него, недостижим по
построению — а значит диагностика, построенная на таком разборе, не работает ни для одного
реального контейнера.

При исчерпании PIN-попыток сертификат из незашифрованной части ДОЛЖЕН (MUST) извлекаться без
пароля и показывать host/user-binding («не та флешка против не тот PIN»). Контейнер без
незашифрованного раздела с сертификатом (старый образец выдачи) ДОЛЖЕН (MUST) давать штатный
исход «сертификат недоступен», а не ошибку разбора.

Извлечённый сертификат НЕ ДОЛЖЕН (MUST NOT) валидироваться против якоря доверия и НЕ ДОЛЖЕН
(MUST NOT) влиять на исход аутентификации — он только диагностика. Ключевой материал этим путём
НЕ ДОЛЖЕН (MUST NOT) разбираться и касаться.

#### Scenario: Cert в нешифрованном SafeBag после исчерпания PIN
- **WHEN** PIN-попытки исчерпаны, а cert лежит в нешифрованном SafeBag (issuance v2+)
- **THEN** cert извлекается без пароля, показывается host/user-binding для диагностики; против anchor он не валидируется

#### Scenario: Ключ в контейнере зашифрован
- **WHEN** контейнер содержит зашифрованный `pkcs8ShroudedKeyBag` — то есть любой контейнер штатной выдачи
- **THEN** сертификат всё равно извлекается: разбор не пытается расшифровать ключ и не прерывается на нём

#### Scenario: Контейнер без открытого раздела с сертификатом
- **WHEN** в контейнере нет незашифрованного `CertBag` (контейнер старого образца)
- **THEN** возвращается «сертификат недоступен» как штатный исход; аутентификация и её диагностика не прерываются ошибкой

#### Scenario: Диагностика не влияет на исход
- **WHEN** сертификат извлечён этим путём
- **THEN** он используется только для показа host/user-binding; решение об аутентификации принимается без него
