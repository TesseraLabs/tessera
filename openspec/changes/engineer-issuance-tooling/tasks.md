## 1. Предусловия

- [ ] 1.1 Убедиться, что `issuer-secret-input` реализован — PIN и пароль ключа запрашиваются лестницей источников
- [ ] 1.2 Убедиться, что `issuer-key-generation` реализован — сборка контейнера и раскладка носителя переиспользуются

## 2. Генерация на активном токене (красные тесты вперёд)

- [ ] 2.1 Тест: после генерации фактические атрибуты перечитываются с устройства и возвращаются вызывающему
- [ ] 2.2 Тест: ключ, у которого фактический атрибут извлекаемости не соответствует запрошенному, отвергается с указанием фактического значения
- [ ] 2.3 Тест: генерация на устройстве с пустым списком механизмов отвергается с диагностикой о пригодности только как носителя
- [ ] 2.4 Тест: существующий ключ с тем же идентификатором или меткой не перезаписывается без подтверждения
- [ ] 2.5 Тест: запрошенный тип ключа вне списка механизмов даёт типизированную ошибку с перечислением поддерживаемых
- [ ] 2.6 Реализовать генерацию в PKCS#11-адаптере
- [ ] 2.7 Прогнать 2.1–2.5 на трёх стендах: подставной модуль (ловим ложь),
      SoftHSM (путь работает), живой Рутокен ЭЦП 3.0 (реальный провайдер) —
      зелёные на каждом
- [ ] 2.8 Тест: активная проба неизвлекаемости — успешное извлечение отвергает ключ
- [ ] 2.9 Тест: `CKA_NEVER_EXTRACTABLE`/`CKA_ALWAYS_SENSITIVE` прочитаны; ключ,
      побывавший извлекаемым, отвергается; невозвращённый атрибут — отказ, не FALSE

## 3. Операция запроса

- [ ] 3.1 Тест: запрос с генерацией не требует отдельного файла открытого ключа, доказательство владения ключом верно по построению

- [ ] 3.3 Тест: собранный запрос не содержит запрошенных расширений, влияющих на права
- [ ] 3.4 Тест: программный ключ сохраняется только зашифрованным, права закрыты для группы и остальных
- [ ] 3.5 Тест: незашифрованного закрытого ключа на диске не остаётся, включая временные файлы

## 4. Операция приёма выданного

- [ ] 4.1 Тест: сертификат, не соответствующий имеющемуся закрытому ключу, прерывает операцию
- [ ] 4.2 Тест: несходящаяся цепочка прерывает операцию
- [ ] 4.3 Тест: истёкший или ещё не наступивший срок прерывает операцию
- [ ] 4.4 Тест: отсутствие роли, неподдерживаемая версия профиля, отсутствие обязательных расширений — каждый случай прерывает операцию с конкретным указанием
- [ ] 4.5 Тест: привязка к устройству показывается как непроверенная; при явно заданном ожидаемом значении расхождение прерывает операцию
- [ ] 4.6 Тест: при непрошедшей проверке на носитель ничего не записано
- [ ] 4.7 Тест: проверка цепочки в приёме идёт тем же кодом, что и проверка на
      устройстве при входе, а не собственной реализацией; общность доказывается
      заменой корня, а не сравнением текстов вердиктов
- [ ] 4.8 Реализовать операцию приёма
- [ ] 4.9 Прогнать тесты 4.1–4.7 — зелёные
