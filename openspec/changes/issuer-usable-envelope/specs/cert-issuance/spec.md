# cert-issuance Delta Specification

## ADDED Requirements

### Requirement: Пригодность выпускаемых рамок делегирования

Выдача НЕ ДОЛЖНА (MUST NOT) порождать сертификат, который по собственным
правилам проверки Engine не может быть использован ни в одном сценарии входа.
Рамки делегирования ДОЛЖНЫ (MUST) проверяться на пригодность до подписи, а не
только на монотонность относительно родителя.

Непригодными ДОЛЖНЫ (MUST) считаться рамки, чьё измерение не допускает ни одного
значения: пустой `allowRoles` (закрытый белый список без элементов не разрешает
ни одной роли) и нулевой `maxTtl` (дочернее звено обязано иметь нулевой срок
действия). Обнаружение непригодности ДОЛЖНО (MUST) прерывать выдачу с указанием
конкретного измерения; частично подписанных артефактов и записей в журнале
выдачи НЕ ДОЛЖНО (MUST NOT) возникать.

Значения по умолчанию для измерений рамок ДОЛЖНЫ (MUST) быть пригодными в
указанном смысле. Умолчание НЕ ДОЛЖНО (MUST NOT) вводиться там, где пригодное
значение зависит от внедрения (имена ролей): в таком случае аргумент ДОЛЖЕН
(MUST) быть обязательным, поскольку угаданное умолчание либо повторяет
непригодность, либо расширяет рамки сверх названного оператором.

Умолчание `maxTtl` ДОЛЖНО (MUST) соответствовать тому, что рамка ограничивает:
у корня парка это срок CA организации, у CA организации — срок листа смены.
Единое значение для обеих операций непригодно по существу.

#### Scenario: Выдача CA без разрешённых ролей
- **WHEN** оператор запрашивает выпуск CA, не назвав ни одной разрешённой роли
- **THEN** выдача отвергается до подписи с указанием, что пустой `allowRoles` не разрешает ни одной роли

#### Scenario: Явно нулевой потолок срока
- **WHEN** оператор задаёт `maxTtl = 0`
- **THEN** выдача отвергается до подписи: под таким CA не проходит ни одно дочернее звено с ненулевым сроком

#### Scenario: Умолчания дают пригодный сертификат
- **WHEN** оператор задаёт только обязательные аргументы выпуска CA
- **THEN** выпущенный сертификат пригоден: под ним проходит выдача листа смены и проверка цепочки Engine
