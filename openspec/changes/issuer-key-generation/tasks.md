## 2. Эксперимент на совместимость (до выбора зависимости)

- [x] 2.1 Собрать контейнер каждым кандидатом (крейт экосистемы либо реализация поверх `der`/`pkcs8`) с сертификатом в незашифрованной части
- [ ] 2.2 Прочитать каждый существующим кодом проверки (`from_p12`): ключ по паролю, сертификат без пароля — **закрыто наполовину, галочка не ставится.** Ключ по паролю читается; сертификат без пароля не читается ни у одного контейнера, включая собранные `openssl` с `-certpbe NONE`. Причина не в писателе: `try_extract_cert_without_pin` зовёт `PKCS12_parse` с пустым паролем, а тот прерывает разбор на нерасшифровываемом `pkcs8ShroudedKeyBag` и не отдаёт уже разобранные сертификаты (см. «Решение 4а»). Критерий станет выполнимым только после починки разбора в `tessera_core`; она вынесена в отдельный change
- [x] 2.3 Прочитать каждый сторонним инструментом (`openssl pkcs12`) — контейнер должен быть пригоден и вне нашего кода

## 4. Сборка контейнера

- [ ] 4.1 Тест: собранный контейнер читается `from_p12` — ключ по паролю, сертификат без пароля — **закрыто наполовину, галочка не ставится** по причине из 2.2. Вместо чтения без пароля через сломанную функцию раскладка закреплена структурной проверкой контейнера: `certificates_without_passphrase` достаёт лист и цепочку, не касаясь пароля, и ни один раздел контейнера не является `EncryptedData`. Сторонним инструментом чтение без пароля подтверждено (`openssl pkcs12 -nokeys -nomacver -passin pass:`)
- [x] 4.2 Тест: самопроверка обратным чтением отвергает результат при расхождении с исходными ключом и сертификатом
- [x] 4.3 Тест: пароль по умолчанию порождается инструментом и не сохраняется ни в каком файле
- [x] 4.4 Тест: пароль отсутствует в argv, логах и журнале выпусков
- [x] 4.5 Тест: заданный оператором короткий пароль отвергается
