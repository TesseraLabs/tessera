## ADDED Requirements

### Requirement: Audit-событие device_number_latched

Engine ДОЛЖЕН (MUST) эмитить audit-событие `device_number_latched` при успешной защёлке номера:
каноническая форма номера, идентификатор наряда, фактическая идентичность железа (prefix8 на
экран, полное значение в журнал). Событие ДОЛЖНО (MUST) попадать в локальный hash-chain журнал.
Отвергнутая попытка защёлки ДОЛЖНА (MUST) эмитить событие с причиной отказа: неверный
контрольный символ, номер вне наряда, истёкший наряд, невалидная подпись наряда, уже
существующая привязка.

#### Scenario: Успешная защёлка
- **WHEN** номер защёлкнут по валидному наряду
- **THEN** эмитится `device_number_latched` с номером, идентификатором наряда и идентичностью железа

#### Scenario: Попытка защёлки на защёлкнутом устройстве
- **WHEN** предъявлен наряд с другим номером на уже защёлкнутом устройстве
- **THEN** эмитится событие отказа с причиной «привязка уже существует»
