## MODIFIED Requirements

### Requirement: Источник device_number

Источник `device_number` ДОЛЖЕН (MUST) отдавать номер устройства только при подтверждённой
привязке номера к железу. Подтверждением ДОЛЖЕН (MUST) служить один из двух носителей:

- device-манифест enrollment-пакета, подписанный доверенным якорем, чей `host_id_hash` совпал
  с идентичностью железа, вычисленной по остальным источникам цепочки;
- локально защёлкнутая привязка (`enrollment-roster`), чья зафиксированная идентичность железа
  совпала с текущей и чей наряд был проверен в момент защёлки.

При наличии обоих носителей приоритет ДОЛЖЕН (MUST) отдаваться манифесту УЦ: он подтверждён
подписью на саму пару «номер + железо», тогда как защёлка фиксирует эту пару локально. Если
носители дают разные номера, источник ДОЛЖЕН (MUST) считаться пустым, а расхождение — попадать
в диагностический лог; выбирать «более удобный» номер источник НЕ ДОЛЖЕН (MUST NOT).

Если ни один носитель не подтверждает привязку — манифеста нет, подпись невалидна, поле номера
пусто, защёлки нет или зафиксированная идентичность железа разошлась — источник ДОЛЖЕН (MUST)
считаться пустым; отдавать номер без подтверждённой привязки он НЕ ДОЛЖЕН (MUST NOT). Пустой
источник обрабатывается существующими правилами цепочки и fallback-политики; новых кодов отказа
не вводится.

#### Scenario: Манифест валиден и привязка совпала
- **WHEN** подпись манифеста проверена и `host_id_hash` совпал с идентичностью железа
- **THEN** источник отдаёт номер устройства как значение `host_id`

#### Scenario: Клон образа на другом железе
- **WHEN** манифест скопирован на другое устройство и `host_id_hash` не совпадает с его железом
- **THEN** источник пуст; при `fallback="deny"` аутентификация отклоняется

#### Scenario: Невалидная подпись манифеста
- **WHEN** подпись device-манифеста не проверяется доверенным якорем
- **THEN** источник пуст (fail-closed), номер не используется

#### Scenario: Номер из защёлкнутой привязки
- **WHEN** манифеста УЦ нет, но есть защёлкнутая привязка, чья идентичность железа совпадает с текущей
- **THEN** источник отдаёт номер из защёлкнутой привязки

#### Scenario: Расхождение манифеста и защёлки
- **WHEN** манифест УЦ и защёлкнутая привязка дают разные номера
- **THEN** источник пуст, расхождение пишется в диагностический лог
