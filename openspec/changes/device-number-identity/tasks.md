## 4. Артефакты, где номер вытесняет идентичность железа

- [ ] 4.1 `device_id` в audit-событиях несёт каноническую форму номера, когда номер определён, и прежнюю идентичность — когда нет; контрольный символ в audit не попадает
- [ ] 4.2 Вход MAC кода принимает сырые UTF-8 байты канонической формы до percent-encoding; percent-encoding применяется только к QR-payload
- [ ] 4.3 Тест на номере со спецсимволами: MAC сходится на обеих сторонах, payload корректно закодирован
