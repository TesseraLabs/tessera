## MODIFIED Requirements

### Requirement: Импорт enrollment-пакета

После flip (`clone-image-bootstrap`) устройство ДОЛЖНО (MUST) импортировать enrollment-пакет,
содержащий per-host удостоверение (`.p12` под PIN — существующий путь) и набор тегов + первый
bundle (роли+CRL). В managed-режиме теги и bundle ДОЛЖНЫ (MUST) проверяться по подписи и
`bundle_version` (механизм `role-store`); в standalone-режиме источником ДОЛЖЕН (MUST) служить
локальный файл под доверием прав ФС. Импортированные теги ДОЛЖНЫ (MUST) попадать только в
доверенный источник `device-tags`; произвольный локальный конфиг тегов НЕ ДОЛЖЕН (MUST NOT)
приниматься как источник.

Device-манифест enrollment-пакета ДОЛЖЕН (MUST) нести номер устройства (`device_number`) и
`host_id_hash` того железа, за которым номер закреплён. Импорт манифеста, чей `host_id_hash`
не совпадает с идентичностью железа, вычисленной по остальным источникам цепочки, ДОЛЖЕН (MUST)
отвергаться (fail-closed) — это отсекает клон образа, перенесённый на другое устройство.
Манифест без номера ДОЛЖЕН (MUST) оставаться допустимым: устройство продолжает работать по
идентичности из железа.

#### Scenario: Managed-импорт с валидной подписью
- **WHEN** импортируется подписанный enrollment-пакет с тегами и bundle
- **THEN** подпись и `bundle_version` проверяются, теги попадают в доверенный источник, устройство становится рабочим

#### Scenario: Битый enrollment-пакет
- **WHEN** manifest пакета не проходит проверку подписи (managed)
- **THEN** импорт отвергается (fail-closed), устройство остаётся в прежнем состоянии

#### Scenario: Манифест с номером и совпавшей привязкой
- **WHEN** импортируется манифест с `device_number` и `host_id_hash`, совпавшим с железом
- **THEN** импорт принимается, номер становится доступен источнику `device_number`

#### Scenario: Манифест с чужой привязкой
- **WHEN** импортируется манифест, чей `host_id_hash` не совпадает с идентичностью железа
- **THEN** импорт отвергается (fail-closed)

#### Scenario: Манифест без номера
- **WHEN** импортируется манифест прежнего вида, без поля `device_number`
- **THEN** импорт принимается, устройство работает по идентичности из железа
