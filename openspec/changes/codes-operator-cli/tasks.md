## 5. Паритет и приёмка

- [ ] 5.1 Тест паритета «один и тот же отказ в CLI и в кабинете идёт из одной проверки ядра»:
      невозможен, пока кабинет работает против TS-порта, а не против WASM-сборки ядра.
      Делается после мержа контракта в open main и re-pin в enterprise — тогда обе обёртки
      зовут один код, и тест становится осмысленным
- [x] 5.2 Хелпер `tests/e2e/helpers/codes-phone.sh` вызывает CLI (`--code-only`), своей формулы
      не имеет; краснота сюиты теперь держится только стендом (.deb с этим кодом ещё не в main)
- [x] 5.3 `cargo clippy --all-features` и дефолтная сборка чисты
